How to remove duplicate contacts in Excel, including the ones Remove Duplicates misses

Written by the maker of Contact Cleaner, a free browser tool. The method below needs nothing but Excel.

What Remove Duplicates does, and doesn't

On the Data tab, Remove Duplicates deletes a row when every column you ticked holds the same value as an earlier row. It ignores capital letters, so ARTA and arta count as the same. Everything else has to match exactly. That means these survive it:

  • a trailing or double space: Arta Berisha and Arta Berisha
  • punctuation: Acme Corp. and Acme Corp
  • the same phone written two ways: +383 44 123 456 and 044 123 456
  • different spelling: Acme Corp. and Acme Corporation

It also deletes straight away, so work on a copy of the sheet.

Step 1: tidy the values into helper columns

Add columns to the right of your data and fill them down. For a name or company in column A:

=LOWER(TRIM(SUBSTITUTE(SUBSTITUTE(A2,CHAR(160)," "),".","")))

TRIM removes leading, trailing and doubled spaces; CHAR(160) is the non-breaking space that web pages and CRMs often leave behind and that TRIM alone does not touch. For an email in column B:

=LOWER(TRIM(B2))

For a phone number in column C, keep only the last eight digits so a country code or a leading zero stops mattering:

=RIGHT(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(SUBSTITUTE(C2," ",""),"-",""),"(",""),")",""),"+",""),8)

Step 2: remove the exact duplicates on the helper columns

Copy the helper columns and paste them as values (Paste Special > Values), then run Data > Remove Duplicates ticking only the email helper column. That removes rows with the same email however it was typed. Use the name helper only if you are sure a name alone identifies a person; it usually doesn't.

Step 3: look at what is left before deleting more

To see duplicates without deleting anything, select a helper column and use Home > Conditional Formatting > Highlight Cells Rules > Duplicate Values, or count them in a new column:

=COUNTIF($D$2:$D$5000,D2)>1

Sort by that column and read the highlighted rows. Two rows with the same phone but different names might be a husband and wife, or a typo, and only you know which.

Where this stops working

Helper columns find values that become identical once tidied. They do not find Acme Corp. next to Acme Corporation, or Blerim Krasniqi next to Blerim Krasnighi. On Windows, Microsoft's Fuzzy Lookup add-in does approximate matching if you can install it. For a long list that is a lot of manual work, which is the case Contact Cleaner is for.
