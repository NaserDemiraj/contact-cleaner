How to clean and merge a contacts CSV before you import it

Written by the maker of Contact Cleaner, a free browser tool. Everything below works in a plain spreadsheet.

Importing a messy list into a CRM or mailing tool copies the mess into a place that is harder to fix. Ten minutes on the file first is cheaper than merging records afterwards.

1. Open it with the right encoding

If Berisha shows as strange symbols, or accented letters are wrong, the file was saved in an older encoding. In Excel, don't double-click the file: use Data > From Text/CSV and try UTF-8 first, then a Western or Central European encoding. In Google Sheets, use File > Import. Fix this before anything else, or you will compare names that only look different.

2. Remove the junk

  • Blank rows: sort by any filled column and delete the empty block.
  • Placeholders like N/A, null or - in email or phone cells: Find & Replace them with nothing, matching the entire cell contents, so they don't count as data.
  • Invalid emails: filter for emails with no @ or no dot after it, and fix or clear them.

3. Make the same thing look the same

Lower-case emails (=LOWER(TRIM(B2))), trim names (=TRIM(A2)) and write phones in one shape. Paste the results back as values and delete the originals only after you have compared a few rows.

4. Find the people who appear twice

Excel's Remove Duplicates works well on a tidied email column, because an email address normally identifies one person. It will not catch the same person with two different emails, or the same phone under different names. Highlight repeats on the phone column too (Conditional Formatting > Duplicate Values) and read them.

5. Merge, don't just delete

When the same person appears in two rows, deleting one row can throw away a phone number or a company that only the deleted row had. Copy the missing details into the row you keep first. Cells that disagree (two different phone numbers) deserve a look; keep both if both are real.

6. Keep a copy and a record

Save the original file untouched, and note how many rows you started and ended with, so a surprise in the CRM can be traced back.
